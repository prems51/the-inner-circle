# The Inner Circle

This is a modern, light-themed responsive website built for **The Inner Circle**, a trading community and education platform. 

This is a freelance project owned by **The Inner Circle** and developed by **Prem**.

## Features

- **Responsive Design**: Beautiful, responsive layout that looks great on desktop and mobile devices.
- **Premium Aesthetics**: A sleek, light-mode design with elegant gradients, glassmorphism effects, and subtle animations.
- **Dynamic Interactions**: Micro-animations on hover and scrolling provide an engaging user experience.
- **Sections**: Detailed components covering Benefits, Journey, Testimonials, Pricing, Why Us, Team, FAQ, and Discord integration.
- **Performance Optimized**: Fast loading speeds using modern frontend technologies.
